# LocalMate 결정 기록 v1.2

기준일 2026-10-22. `DECIDED`는 사용자와 기획 대화에서 확정한 제품 방향이고, `DRAFT`는 구현 기본안이며, `OPEN`은 외부 확인이 필요합니다. 팀 합의 후 변경 사항을 이 파일에 기록합니다.

| ID | 상태 | 항목 | 결정 또는 다음 확인 |
|---|---|---|---|
| D-01 | DECIDED | 목표 서비스 | 소상공인의 고객 반응과 운영정보를 분석하고 점주 승인을 받은 내부 업무만 실행하는 범용 AI 비서 |
| D-02 | DECIDED | 전달 형태 | 독립형 반응형 웹; 네이티브 앱과 외부 플랫폼 직접 게시 제외 |
| D-03 | DECIDED | 업종 | 카페 골든패스, 미용실 확장성 시연 |
| D-04 | DECIDED | 승인 정책 | AI의 변경 제안은 Owner 승인 후 서버가 실행; 외부 게시/예약 변경은 제외 |
| D-05 | DECIDED | 데이터 | 합성 데이터 시연 허용; 실제 점주 인터뷰 완료나 실측 성과를 주장하지 않음 |
| D-06 | DECIDED | 비용 | 별도 유료 결제 없이 개발. 무료 지원 확인 전 클라우드/모델 과금 호출 금지 |
| D-07 | DRAFT | 스택 | React + TypeScript + Vite / FastAPI / 개발·시연용 SQLite. 구체 구현 전 양 개발자 확인 |
| D-08 | DRAFT | API 계약 | `docs/04_API_CONTRACT.md`를 베이스라인으로 잠정 채택. 필요 시 계약 PR 승인 |
| D-09 | DRAFT | 화면 | `docs/11_UI_FUNCTIONAL_SPEC.md`의 화면·버튼·동작을 필수로 하되 디자인/배치 자율 |
| D-10 | OPEN | 내부 LLM | Open AI Service Hub 개발키로 `hyperclovax-seed-32b` 테스트 가능성 확인. 실제 키 발급·성능·도구호출·한도 검증 후 최종 선정 |
| D-11 | OPEN | 외부 네이버 로컬 데이터 | 정식 API 권한, 가격, 사용 가능한 필드 확인 전 P1로 유지 |
| D-12 | OPEN | 운영 DB·배포 | 초기 P0는 로컬 재현 중심, 외부 배포·운영 DB는 비용과 보안 검증 후 확정 |

## 팀 합의 로그
- 2026-10-22: D-01~D-06 사용자의 기존 결정 반영.
- 개발자 A/B: 위 DRAFT/OPEN을 검토하고 이름·날짜·결과를 추가 기록. 미결 상태라고 해서 P0 UI/모의 데이터 작업을 중단할 필요 없음.
