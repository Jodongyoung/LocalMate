# LocalMate 데모 및 피칭 시나리오 v1.2

## 60~90초 골든패스
1. **문제**: 카페 점주가 여러 리뷰에서 반복되는 운영 문제를 직접 찾아 후속 업무를 기록하기 어렵다는 가설을 제시합니다.
2. **데이터**: 합성 리뷰·매출 기록과 사업장 정책을 불러옵니다. 합성 데이터 사용을 화면/발표에서 밝힙니다.
3. **분석**: AI가 리뷰의 대기 불만을 분석하고 근거 리뷰와 DB 집계값을 보여 줍니다.
4. **선제 인사이트**: 점주 채팅 없이도 대시보드에 반복 문제 및 제안이 나타납니다.
5. **비서**: 점주가 원인을 질문하면 AI가 근거 없는 추측을 피하면서 데이터의 한계를 알려 줍니다.
6. **제안**: 내부 업무 생성과 답변 초안 저장 제안을 보여 줍니다.
7. **점주 승인**: 승인 전에는 업무 0건, 승인 후 실제 작업이 한 건 생성되고 이력이 남습니다.
8. **결과**: 동일 승인 재요청도 중복 작업 없음. 미용실 사업장 전환 시 예약 도구를 사용해 범용성을 보여 줍니다.

## 발표 근거
- 인증된 테스트 계정/사업장별 격리, 분석 근거 인용, 서버 집계, 실행 기록, 실측 시간·완주율을 증거로 확보합니다.
- 사용자 인터뷰는 하지 않은 것으로 표시합니다. 실제 데이터 성능·절감률을 임의로 발표하지 않습니다.
- 촬영된 시연 백업 영상과 고정 시드를 보유하여 오프라인/모델 장애에 대비합니다.
- 발표 시간과 상세 배점은 공식 공지 확인 전 가정입니다.
