# LocalMate 화면 표현 규칙 v1.2

## UI 역할
- **필요한 화면·버튼·동작**: `docs/11_UI_FUNCTIONAL_SPEC.md`를 단일 기준으로 삼습니다.
- **디자인 자율성**: 이 프로젝트는 와이어프레임·고정 좌표·고정 색상·폰트 스케일을 규정하지 않습니다. 프론트엔드 담당자가 직접 결정하고 Qwen으로 구현할 수 있습니다.
- PC/모바일에서 핵심 흐름을 사용 가능하게 하고, 390px 뷰포트에서 승인 버튼을 누를 수 있어야 합니다.

## 컨텐츠/상태 표시
- AI의 숫자는 실제 DB 집계·집계 기간·근거 ID를 함께 표시합니다. 분석 실패=중립이 아닙니다.
- AI 제안/승인 대기/승인/거절/실행 중/성공/실패/결과 미확정 상태를 구분합니다.
- 데이터 출처(합성/사용자 제공/실제), 모델 실행(실제 모델/Mock/캐시)을 명시합니다.
- 사용자 피드백: 입력 오류, 사업장 권한 오류, 데이터 부족, 공급자 장애, 재시도 안내를 서로 다르게 보여줍니다.
- 상태/성능 지표를 임의 생성하거나 '실제 소상공인 인터뷰로 검증' 문구를 사용하지 않습니다.

## 책임
- 프론트엔드 담당자: 화면 구조/내비게이션/컴포넌트/문구, 390px·1440px E2E.
- 백엔드 담당자: API 계약·상태·숫자·승인/실행 결정.
- 두 사람: 승인 UI의 안전 기준, 사업장 격리, 수용 테스트 공동 검증.
