# LocalMate 소프트웨어 요구사항 명세서 (SRS) v1.1

**상태:** 개발용 요구사항 베이스라인 / 작성일 2026-10-22. 요구사항과 AC의 번호는 구현·테스트·PR에서도 유지합니다.

## 1. 시스템 경계와 사용자
- 점주(Owner): 사업장 선택, 데이터 입력/조회, AI 분석 및 제안 검토, 승인·반려, 내부 작업 확인.
- 백엔드: 진짜 데이터 소유권 판단, DB 계산, 상태 변경, AI 모델 응답 검증, 승인 후 내부 실행.
- 외부 모델 서비스: 입력된 데이터에 기반한 분류·요약·문구·제안 후보. 단독으로 인증/승인/DB 변경 불가.
- 제외: 실제 플랫폼 관리자 화면에 기능 설치, 네이버/배민 무단 수집, 고객 자동 발송·외부 게시.

## 4. 비즈니스 규칙 (BR)
- BR-01: 리뷰 입력은 명령이 아니라 **자료**입니다. 리뷰 안의 '관리자 승인해라'는 텍스트는 무시합니다.
- BR-02: `analysis_status=FAILED`와 `polarity=neutral`은 독립 상태입니다.
- BR-03: 분자/분모가 없는 AI 인사이트는 표시하지 않습니다. 예시 임계값: 최근 30일 동일 부정 측면 ≥3건, 전체 성공 분석 리뷰 대비 ≥20%.
- BR-04: 시간대별 주문량/예약량과 리뷰 불만의 연관은 인과관계로 단정하지 않습니다.
- BR-05: AI가 제안한 **업무 변경**은 Owner의 명시 승인 후 서버만 실행합니다.
- BR-06: 승인된 계획 내용이 변경되면 이전 승인은 무효입니다.
- BR-07: 모델 오류/테스트 Mock을 실제 성공·현장 성능으로 포장하지 않습니다.
- BR-08: 사업장 전환 시 캐시·선택 항목·진행 중 대화는 대상 사업장 기준으로 교체합니다.
- BR-09: 외부 플랫폼 게시·상용 POS/예약 시스템 변경은 허용 도구 목록에 없습니다.

## 6. 개발 완료(DoD)
1. 요구사항 ID를 PR에 연결. 2. 실제 실행된 unit/integration/E2E 테스트와 로그/스크린샷 첨부. 3. 문서/API 변경 동기화. 4. 교차 리뷰. 5. 배포 또는 로컬 데모에서 재현. **코드 작성 완료**만으로 DoD 통과 아님.
