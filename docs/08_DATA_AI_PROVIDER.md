# LocalMate 데이터 및 AI 제공자 정책 v1.2

## 데이터와 실증
- 합성 리뷰·매출·예약 데이터를 시연에 사용합니다. 실제 사용자 인터뷰·현장 데이터와 구별합니다.
- 합성 데이터는 반복 가능한 고정 시드·출처를 남깁니다. 실제 고객 실명·전화번호 사용 금지.
- 카페 매출·미용실 예약 합계, 반복 불만 건수, 비율은 백엔드 DB에서 계산. 모델이 계산값을 임의 생성하지 않습니다.
- 미확인 지역 통계·트렌드/리뷰는 표시하지 않습니다. 합법적인 공식 API 연동은 P1입니다.

## AI 모델 선택
- Qwen은 코드 개발용 AI 도구입니다. 서비스 내부 AI는 별도 공급자 어댑터로 처리합니다.
- HyperCLOVA X/CLOVA Studio는 무료 접근·실제 인증/호출 조건을 확인할 때 우선 검토합니다. 유료 결제 필요 시 동작 중단/학교 제공 모델로 대체합니다.
- 아직 모델 계정, 무료 크레딧, OpenAI 호환 사양, 구조화 출력/Tool Calling, 쿼터가 확인되지 않았습니다.
- 모델 Mock은 테스트 전용이며 라이브 모델 응답으로 소개하지 않습니다. 캐시 재사용·실제 라이브 실행도 구분합니다.
- 모델 출력은 코드/명령/SQL로 실행하지 않습니다. 도구 허용목록·스키마·근거·승인 상태는 서버가 검사합니다.

## 모델 전환시 검증
- 인증 성공 / 최소 입력과 출력 / 구조화 JSON / 오류 코드와 타임아웃 / 비용 한도 / 로그의 민감정보 부재 / 인용 근거 확인.
- 새 공급자 도입은 기존 P0 구조를 변경하지 않도록 provider adapter 뒤에 배치합니다.
